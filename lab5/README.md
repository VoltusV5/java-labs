# Лабораторная работа №5. MVC и работа с файлами

Вариант 21. Автоматическая кофемашина. Приложение продолжает ЛР4.

## Сборка и запуск

Нужны JDK 17 или новее и Maven. Выполните команды из папки `lab5`.
В Windows перед запуском в PowerShell или cmd установите кодировку консоли командой `chcp 65001`.

```shell
mvn clean package
java -jar target/lab5.jar --help
java -jar target/lab5.jar --interactive
java -jar target/lab5.jar --show machines.txt
java -jar target/lab5.jar --replace backup.txt machines.txt
java -jar target/lab5.jar --watch machines.txt 5
java -jar target/lab5.jar --csv machines.txt changes.csv 5
```

`--replace` копирует содержимое источника во временный файл рядом с назначением и затем заменяет назначение одной операцией. Если файловая система не поддерживает такую замену, команда сообщит об ошибке.

`--watch` и `--csv` читают файл сразу, а затем ждут указанное количество секунд перед каждым следующим чтением. Чтобы остановить процесс, нажмите Ctrl+C. При временной ошибке чтения программа сообщает о ней и повторяет попытку через заданный интервал. Ошибка записи CSV завершает команду с сообщением.

## Формат входного файла

Сохраните файл в UTF-8. Каждая кофемашина описывается отдельным блоком. Тип блока — `DripCoffeeMaker`, `LatteMachine` или `GrinderCoffeeMachine`.

```text
DripCoffeeMaker {
    Manufacturer: Philips;
    WaterCapacity: 1200;
    Water: 500;
    Strength: 2;
}
```

## Структура кода

- `model` хранит состояние кофемашин и проверяет допустимость действий.
- `controller` обрабатывает ключи запуска и действия интерактивного меню.
- `view` выводит меню, состояния и сообщения, проверяет ввод с клавиатуры.
- `io` читает текстовый файл, заменяет файлы и записывает CSV.
